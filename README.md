## 🚀 Projects (My Learning Journey)


### 💻 Systems Engineering Studies

#### **Mini-Docker — Container Runtime from Scratch**
*Deconstructing how containers actually work.*
*   **What I Built**: A functional container runtime using raw Linux system calls (namespaces, cgroups, chroot).
*   **Why**: I wanted to understand "isolation" beyond just running `docker run`.
*   **Key Learning**: The complexity of securing processes and how Linux namespaces provide the illusion of a separate system.
*   [View on GitHub](https://github.com/Tarunpathak001/Mini-Docker)

#### **Mini Redis-Cassandra — Distributed Key-Value Store**
*A distributed database built from scratch to verify theoretical concepts.*
*   **What I Built**: A Python-based distributed key-value store featuring sharding, replication, and Raft-inspired consensus.
*   **Key Learning**: Implemented Gossip Protocol for failure detection, AOF/Snapshot persistence, and Anti-Entropy using Merkle trees. Moving from theory to a working P2P mesh architecture.
*   [View on GitHub](https://github.com/Tarunpathak001/Mini-redis-cassandra)
